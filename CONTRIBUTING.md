# Contributing

- Use focused branches and pull requests.
- Keep gameplay balance in JSON rather than adding level-specific conditionals.
- Update docs when public config fields, save schema, controls, or build steps change.
- Never commit credentials, tokens, private keys, or personal data.
- Prefer small, reviewable commits using Conventional Commit prefixes.
- Before requesting review, run `npm run build` and test one early, one mid-game, and one late-game level.
